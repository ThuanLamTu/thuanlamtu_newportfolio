# Xin chào, mình là Thuận Lâm Tự 👋

### Full-Stack Developer

Xây dựng các ứng dụng web hiện đại, tối ưu trải nghiệm người dùng và sẵn sàng triển khai thực tế.

---

## 👨‍💻 Giới thiệu

Mình là **Thuận Lâm Tự**, một Full-Stack Developer yêu thích phát triển các ứng dụng web hiện đại bằng **React, Node.js, Express và MongoDB**.

Mình đã có kinh nghiệm phát triển và triển khai các website thương mại cho khách hàng thực tế, từ giai đoạn phân tích yêu cầu, xây dựng giao diện, tích hợp API đến đưa sản phẩm lên môi trường production.

Hiện tại mình tiếp tục trau dồi kỹ năng về kiến trúc phần mềm, tối ưu hiệu năng và phát triển những sản phẩm có tính ứng dụng cao.

---

## 💼 Kinh nghiệm thực tế

### Freelance Full-Stack Developer

- Đã hoàn thành và bàn giao nhiều website thương mại cho khách hàng thực tế (tiêu biểu như Clean5S, Dara Beauty Center...).
- Làm việc trực tiếp với khách hàng để phân tích yêu cầu và triển khai giải pháp.
- Thiết kế giao diện Responsive trên Desktop, Tablet và Mobile.
- Xây dựng ứng dụng trò chuyện thời gian thực (Real-time Chat App).
- Xây dựng dự án số hóa và truyền thông di sản văn hóa làng nghề truyền thống.
- Triển khai ứng dụng lên **Vercel** và **Render**.
- Bảo trì và cập nhật website sau khi bàn giao.
